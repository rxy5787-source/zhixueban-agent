# 第三方 Codex Skills 来源与许可证

本仓库以下三项项目级 Skill **改编**自 `obra/superpowers`，不是原仓库的逐字复制，也不是在用户电脑上全局安装的插件：

- `systematic-debugging`：问题复现、证据定位、最小修复
- `test-driven-development`：Red-Green-Refactor、行为测试
- `verification-before-completion`：执行证据、质量验收、完成前核验

原仓库：https://github.com/obra/superpowers

参考版本：`22f0b463e7a5e579904dd6211a520321035526f7`（2026-11-14 查询时主分支提交）

原作者：Jesse Vincent。许可证：MIT。适配改动包括中文说明、收缩触发范围、与知学伴现有目录对齐、移除插件环境依赖及避免自动删除现有代码。
