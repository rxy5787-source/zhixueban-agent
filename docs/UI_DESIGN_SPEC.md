# 知学伴 Web 设计规范

第一轮采用「森林文献馆」方向，覆盖首页、学习对话、知识库目录和详情。预览以 393 px 为移动端基准，页面随实际视口响应。

## 改版前审查

- 首页把插画、Composer、最近出题和页头任务同时放在首屏。按钮缺少清楚的主次关系，较窄视口的输入工具栏依赖固定列宽。
- 知识库以拟物书架呈现，主题名称在封面和说明里重复。资料数与题目集数容易被缩小的正文掩盖。读取失败原先静默，容易与空库混淆。知识点有内容、没有文档时，也可能出现空状态。
- 出题页已经使用后端任务状态，支持部分结果、重试、练习及归档。题干、解析与出处的字号差异较大，步骤和错误提示分散。其内容层级留待专项改版。
- 个人页已有编辑、偏好、学习记录与掌握分析。手帐插画和数据面板使用两套视觉语言，报告仍适合放在个人中心和对应知识库。
- 基础样式与手帐覆盖层同时设定颜色、圆角和按钮间距。已有任务轮询、对话上下文和 BKT 逻辑属于功能层，本轮沿用这些接入点。

## 视觉方向

- **森林文献馆**采用纸白、森林绿、鼠尾草绿和少量暖金。中文衬线用于展示标题，无衬线用于正文和操作。书脊帮助区分主题，资料数量在同一行内可扫读。
- **现代研究台**采用冷灰、蓝灰及较紧的无衬线布局，可以把集合状态、活动和文档列表并排显示。适合多资料桌面操作，移动端需要更复杂的优先级排序。

采用第一种。当前开始学习的路径很短，首页先建立清楚的一个动作，随后再在对话页提供输入、附件和归档工具。

## 导航与组件

- `#home` 展示品牌与「开始学习」。`#home/study` 承载学习对话和最近出题入口。现有任务与练习保留原哈希链接。知识库内打开对话会带上所选归档目标。
- 书目条目由书脊、主题名、主题描述及归档计数组成。单列移动端、双列宽屏。搜索结果提供计数、空状态、清空搜索。同步失败保留当前可见目录并提供重新读取。
- 对话编辑区的文本、附件和上传反馈共享一个容器。附件可单独移除，浏览对话时编辑区随内容滚动。选择归档主题和历史任务使用既有弹层。
- 主按钮使用森林绿实底，次按钮使用鼠尾草底，文字入口服务返回、回收站等轻操作。标题随页面层级改变，反馈采用文字加背景色。焦点使用 2 px 描边，输入框与搜索框显示包含焦点的边框。

## 设计令牌

- 画布 `#F7F6EF`，表面 `#FFFEFA`，次表面 `#EFEFE6`，分隔 `#D9DDD1`。正文墨色 `#202C25`，次要文字 `#586357`。
- 主色 `#243F32`，按压色 `#182F25`，柔和表面 `#E2E9DC`，点缀金 `#8A622D`。焦点 `#4C725A`，错误文字 `#913D30`、背景 `#F9EAE4`。禁用使用独立前景与背景。
- 展示标题用 Noto Serif SC 的系统回退链，正文用 Noto Sans SC 的系统回退链。正文 15 px，辅助文字 13 px，输入 16 px，正文行高 1.75。字体由设备本地提供。
- 间距以 4 px 递增，卡片圆角 14 px，控件圆角 8 px。主要交互触控区 48 px。阅读区最大 760 px，工作台最大 1100 px，容器达到 650 px 后首页和书架采用双列布局。
- 纸面阴影用于输入容器，叠页阴影只在首页图形使用。遵循 `prefers-reduced-motion`。核心配色实算对比度为正文 13.38:1、次要文字 5.81:1、主要按钮 11.36:1、错误提示 6.15:1。

## 验证与迁移

- 运行 `npm.cmd run check` 与 `npm.cmd run build`。Chrome Playwright 检查 360、393、412 和 1366 px 的首页、对话、知识库、键盘进入、文件选择与移除、搜索、详情跳转及导航，并额外检查 650 px 双列断点。基线与新版截图使用相同的浏览器视口。
- 用项目 SQL 短 TXT 和本机 Qwen3 1.7B 跑过真实浏览器提交、后台任务恢复、答案解析、提交练习、知识点分析和题目集归档。建库、移入回收站和恢复使用独立验收数据。
- 本轮未逐项重跑所有 PDF、DOCX、图片推理、云端试用以及长时间性能场景。个人中心、报告与出题页保留现有布局，第一轮共享新的基础色与控件规范。
- Android 后续可用 Material 3 颜色角色映射语义令牌，间距与触控区映射 dp，字号映射 sp 并遵循系统字体缩放。优先迁移首页、学习对话和主题条目，再按读题流程迁移状态、解析及报告。沿用已有接口和数据层。
- 可编辑 Figma 文件包含首页、学习对话及知识库的 393 px 画板。代码保留交互状态的最终实现。[打开设计稿](https://www.figma.com/design/3Z0bqKYML9IcguhtLcIUSW)

在项目根目录运行 `pwsh -File tools/start-web-study-preview.ps1 -PythonProject ./python-ai -Port 18122` 可重新构建并启动本机预览。真实生成使用本机已运行的 Ollama 和 Qwen3。
