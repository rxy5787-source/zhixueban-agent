# 知学伴生成质量评测

每轮使用同一份资料、相同要求和相同目标题量。保留旧版、优化版和待测模型的原始输出。人工评分时隐去版本，并对照原文核查。以下 20 条是评测题单和预期标准，未执行的样本不计入结果。

- **事实有依据**：逐条检查正文、解析和引用是否一致。关键事实错误、答案不唯一、或依赖没有提供的图表，判为不可用。
- **覆盖目标**：分别记下请求涉及的概念及输出实际覆盖的概念。比较请求要覆盖双方，并明确差异。
- **练习价值**：口诀要有可回忆的提示和对应含义。填空要考关键知识且题干有线索。选择题优先考应用或辨析，干扰项要同类且可排除。明确要求基础记忆的样本按其目标评价。
- **运行指标**：记录可用输出数、实际题数、总耗时、模型调用数和失败原因。整批结束后汇总人工可用率、中位耗时。自动复核结果作为参考。

## 计算机系统讲义

1. 口诀：区分 ALU 与 AC。覆盖运算、提供数据及暂存结果，聚焦这两个部件。
2. 口诀：区分 PC 与 IR。能回忆下一条指令地址与当前指令的差异。
3. 口诀：区分 AR 与 DR。能回忆访问地址与传送数据的差异。
4. 口诀：概括运算器这一节。词句应对应资料同一主题，有原文可查。
5. 问答：ALU 和 AC 都在运算过程中出现，具体分工是什么？解释两者关系。
6. 问答：PC 与 IR 分别保存什么？回答需指明下一条指令与当前执行指令。
7. 问答：为什么把 PSW 与 DR 混为一谈会出错？分别解释条件码与数据传送。
8. 填空：从 PC 和 IR 的作用各选一个关键术语挖空。题干能提示唯一原文术语。
9. 填空：考查状态条件寄存器保存什么。避免把普通动词挖空。
10. 选择题：运算结束后要暂存结果，哪个部件合适？选项为同类部件。
11. 选择题：要找到下一条指令的位置，应查看哪个部件？解析能从原文推出。
12. 选择题：访问指定内存单元时需要保存它的地址，哪个寄存器合适？干扰项可排除。

## SQL 短资料

13. 口诀：区分 WHERE 和 HAVING。两者对应的筛选阶段明确。
14. 问答：先过滤原始行还是先分组？解释资料中的先后关系。
15. 填空：考分组前的行过滤。空格周围保留可区分分组前后的线索。
16. 填空：考分组后的结果过滤。答案与原文一致。
17. 选择题：按部门分组前先排除某些原始记录，应选哪个子句？四项为 SQL 子句。
18. 选择题：只保留满足聚合条件的分组，应选哪个子句？说明为什么分组前过滤不适用。
19. 基础选择题：明确要求只记忆 WHERE 的作用。题目满足基础目标，选项依然互斥。
20. 缺失依据：只给 SQL 短资料，要求说明 TCP 握手序号变化。不得用 SQL 原文冒充依据。

## 本轮运行

实际用原 Word 的已解析正文和同一条 ALU / AC 口诀要求做对照。覆盖多个知识点、题型及 4B 模型的完整盲评仍待执行。

使用 Qwen3 1.7B 在同一份 Word、同一要求下实测，旧版给模型 14 条候选片段，最终版给 2 条。最终版输出「ALU算术逻辑，AC存结果」，两条解释分别与原文一致。单次记录约 24.6 秒与 27.1 秒，后者含自动复核，单次记录不能代表平均速度。另验证 SQL 查询应用题可生成并通过原有独立复核，且用 SQL 文档解释无关 TCP 知识的请求会在生成前拒绝。
