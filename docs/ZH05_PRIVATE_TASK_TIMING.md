# ZH-05：学习任务阶段耗时与安全观测

当前仅给 **Web浏览器试用空间** 增加任务级只读诊断接口。调用者必须先使用有效会话，接口仅访问该空间数据库中存在的任务，不接受用户路径、模型提供的工具名或其他浏览器的任务ID。

`GET /api/generation-tasks/{task_id}/timing`

## 诊断指标

- `queueWaitMs`：从建任务到领取任务的时间。新任务的 `claim()` 会记录受控“准备解析”事件；没有这条记录的旧任务显示 `null`，不能从第一条普通状态消息猜测排队时间。
- `phaseElapsedMs`：各阶段状态事件之间的**墙钟间隔近似统计**。解析、OCR、知识点、生成、自动质量初筛、准备与检查点使用固定枚举。解析阶段可能包含等待、I/O、异常处理；生成阶段可能包含网络等待/模型响应；**不是独占CPU时间、单次Qwen推理时间或准确的OCR耗时**。
- `phaseIntervals`：原始事件间隔顺序与毫秒数，仅含阶段枚举和非负耗时；不包含原始阶段名称。
- `archiveCallbackMs`：WebStore执行自动归档回调的耗时（不包括事务提交）。旧任务和不具备自动归档回调的任务返回 `null`；`0` 表示当前系统计时精度下非常快，不等于证明无开销。
- `terminalWallTimeMs`：从提交到完成/失败/取消/中断的总墙钟时间；仍在队列或处理中时为 `null`。
- `errorCategory`：受控枚举 `task_failed`、`task_cancelled`、`task_interrupted`；成功返回 `null`。不提取或外传异常消息中的私有资料。
- `lastObservedPhase`：最后一个归类成功的进度阶段；并不证明该阶段是失败根因。

## 安全约束

1. 浏览器会话确定当前 `TrialStore`；接口在服务端联结 `web_tasks` 与 `jobs` 并验证 owner。外来任务ID一律404，无会话401。
2. 仅在服务端保存任务事件，**新增遥测接口只返回数字、阶段白名单、固定错误枚举和任务ID**。即使原阶段字符串包含上传文件名或错误详情，也不会返回原文。
3. 不返回模型提示词、生成题目、文件正文、账号Cookie、Bearer Token、日志异常原文、用户上传路径或数据库位置。
4. 数据库以新增独立 `job_archive_metrics` 表存储归档回调耗时；不会迁移或清空已有任务。
5. 自动化测试覆盖跨空间越权、敏感内容过滤、队列领取计时、归档回调、空事件和系统时间回拨。

## 复现与局限

现有Web CI会编译React并打包Python后端，执行 `web-prototype/deploy/test_web_trial.py`。独立技术验收不用真机或Ollama，测试会使用固定数据/模拟状态推进，但**不会把它当作Qwen真实运行耗时**。

真正测量本地Ollama性能仍需以后在原机运行，记录机器配置、模型参数、文档和任务环境。当前任务侧重于可审计、隐私安全的时间与错误分类框架。阶段事件不是精确 Span，未来可以基于此逐步升级成结构化计时。
