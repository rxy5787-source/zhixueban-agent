# 知学伴 Web 端功能测试报告

2026-11-17 · Windows · Chrome（Playwright，393 × 852）· 本机 FastAPI 和 Ollama

## 范围和发布基线

以 GitHub `main` 的 `d76e9e8` 为起点，在独立分支测试并修复 Web。测试使用自编的光合作用短文，覆盖通用学习场景。Android UI 适配和真机测试暂缓。

主分支包含按固定步骤执行的解析、生成、质检与归档 Worker。检查了独立的 Phase 45 集成分支 `2ba6989`，其中有有界技能调度、弱点学习计划、确认执行、审计和恢复逻辑。该分支相对测试基线多 148 个提交。其运行结果单独验收，本报告的主分支证据仅覆盖现行 Worker。

## 结果与证据

- **通过 · 首页和学习对话入口。** 修复前 Uvicorn 记录 `GET /api/study-capabilities → 404`，首页退回普通出题页。部署入口注册学习对话路由后，Chrome 获得 200 并显示「发送学习要求」。API 回归验证未建立访客会话时返回 401，已建立会话时仍会校验父任务权限。
- **通过 · 文件上传与解析。** Chrome 一次选中 TXT、PDF、DOCX、PNG，提交返回 202。真实任务达到一道题目标后跳过了余下三个文件。另逐个通过实际解析器读取四份文件，均提取 221 字符。PNG 走 OCR，DOCX 走正文，PDF 走文本页。该清晰图片未触发 Qwen-VL。
- **通过 · 真实 Qwen 出题、知识点与任务状态。** 任务 `4a2c1a10…` 依次显示解析、生成、复核和完成。SQLite 记录 `generation` 和 `batch_review` 均调用 `qwen3:1.7b`，耗时分别约 167 秒和 57 秒。生成题考查吸收光能的结构，正确答案 B「Chlorophyll」，原文明确支持。Chrome 展开解析，核对原文依据可见。模型按英文资料输出英文题，未单独验收指定输出语言。
- **通过 · 自动批改、BKT 和薄弱点。** Chrome 故意选错，结果记录答对 0/1。叶绿素掌握估计约 12.1%，`reviewPriority=true`；学习分析显示「按薄弱点出题」。
- **通过 · 自动归档并重新打开。** 任务显示已保存 1 道，Chrome 从知识库中的 AI 题目集打开原任务，任务 ID 一致。
- **失败 · 真实薄弱点复练提交。** 修复了入口把练习误识别为问答的风险，预填要求明确指定四选一。Chrome 已通过弱点入口选择资料并提交，后端在模型准备检查阶段返回 503，Ollama `/api/tags` 请求超时。原文件仍保留在界面，可继续重试。真实模型复练尚未完成。
- **通过 · 刷新、浏览器重启和隔离。** 生成期间刷新保留原任务；重新启动同一 Chrome 用户目录后仍可查看原任务，另一个 Chrome 会话猜测原任务 ID 返回 404。接口回归同时验证两个访客各自的题目、回执、资料和答题记录。
- **通过 · 重复点击和任务查询网络异常。** Chrome 双击提交后，任务列表只增加一个任务。Playwright 中断一次任务查询，点击「重新查询」后恢复并能展开解析。断网中上传的完整浏览器流程未测试。

## 未实现、未测试与遗留问题

- **未实现于当前主分支。** 从历史知识库直接选择已保存的资料完成薄弱点复练。有可沿用的当前对话资料时可继续对话，其他情况下需重新选择资料。Phase 45 的学习计划提供已有资料选择和确认执行入口。
- **未测试。** Phase 45 动态 Agent 技能调度的真实浏览器和模型执行、强制触发 Qwen-VL、每种文件独立通过真实 Qwen 生成，以及跨浏览器恢复完整对话草稿。浏览器重启的通过证据限于同一用户目录内的任务与题库。
- **遗留问题。** 实测文本推理和复核合计约 224 秒，最初 180 次轮询的浏览器检查先于任务完成退出。恢复原任务后继续验收。该结果用于记录本机延迟，样本数为一。

本机 Web 构建、部署打包与 14 项接口回归通过。接口测试中的模型替身用于会话和边界验证。真实题目、答题和归档的证据来自本机 Ollama 会话。
