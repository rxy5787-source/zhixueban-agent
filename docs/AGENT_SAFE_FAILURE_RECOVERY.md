# Agent安全故障恢复决策（只读）

## 作用

当用户确认过的学习任务发生Qwen超时、原文解析失败、视觉依据无法验证、质量初筛未通过、Worker中断或取消时，用**确定性普通代码**给出保守建议。此阶段不创建新的Agent Skill，不调用大模型、不自动重试、不修改数据库或BKT。

- **任务仍在排队/运行** → `wait`
- **成功完成** → `complete`
- **部分完成或失败但已有候选接纳** → `review_accepted`（核查已接纳的内容；不能推断事实正确）
- **用户取消** → `stop`
- **已存在重试任务** → `open_existing_retry`（避免重复创建）
- **原始上传资料不存在、已删除或被移入回收站** → `replace_source`
- **解析失败/原文不可读** → `replace_source`
- **需要人工核实视觉依据或自动质检未通过** → `manual_quality_review`
- **记录明确的模型超时** → 最多建议一次 `retry_with_confirmation`
- **服务中断** → 最多建议一次 `retry_with_confirmation`
- **其他未分类异常** → `inspect_failure`（不猜测、不自动执行）
- **已经重试过一次** → `manual_quality_review`（建议不再盲目重试）

## 真实Web接口

`GET /api/generation-tasks/{task_id}/recovery-advice`

使用已签名的浏览器会话访问当前试用空间专属SQLite。任务必须属于当前空间；无登录返回401，跨浏览器任务ID返回404。

服务端遍历已保存的 `web_task_retries` 链，计算**实际重试深度**，而不是相信浏览器或模型提交的计数。循环或异常长链拒绝给出恢复建议。既有重试的任务ID仅从当前空间库里返回，不能凭空填入别人的ID。

返回结果只包含受控状态、失败类别、下一步建议、是否需要人工确认、是否已有重试任务、允许建议的剩余重试次数。**不返回**原文件、模型响应、提示词、学生学习记录、异常原文、源文件路径、个人身份或密钥。

## 限制

- 这是可解释、只读的保守恢复建议，不是自动执行引擎。
- 建议最多重试一次**不是**强制的服务端全局重试配额：现有用户手动重试API仍由其原有任务限制控制。要增加真正的统一重试上限，需要单独修改重试API和兼容既有任务数据。
- 不能单靠失败类别识别真正的错误根因；原始错误文字可能不可信，因此除了固定的模型超时标识，不按自由格式文本“猜错”。
- 本阶段运行的是固定模拟失败场景的CI；**尚未进行真实Qwen故障注入或真机测试**。
- 等经过真实失败数据验证，只有发现Agent确实需要新的受控、可复用执行职责，才考虑新建Skill，并先说明收益与安全边界。

## 自动测试覆盖

1. 运行中、成功、部分完成、取消、未知错误分类。
2. 解析失败、视觉证据不足、质检拒绝、模型超时、服务中断与重试深度。
3. 不泄露私有学习资料和异常原文、不执行模型产生的任意工具名称。
4. Web会话隔离、跨访客访问拒绝、只读不创建任务，以及原重试API返回的回执复用。
5. 缺失原始资料建议替换，不误判为可重试。
